Crontab:
-------
Schedule commands or scripts to run automatically at a specific time or interval.
or
"Crontab is a Linux scheduler used to automate recurring tasks. Cron daemon runs in the background and executes commands or scripts based on the schedule configured in crontab. It is commonly used for backups, monitoring, log cleanup, and automation jobs.

It is mainly used in DevOps for --> backups,log cleanup,monitoring scripts,reports,automation jobs

Real Example

You created a script: /app/disk-check.sh
Instead of manually running:
sh disk-check.sh
every day, configure cron --> Run automatically every day at 2 AM/other times --> That is called a cron job.


Cron has two parts/components:
crond service
crontab entries

1)crond service --> Background daemon/service.

Check 				---> systemctl status crond
Start 				---> systemctl start crond
Enable after reboot ---> systemctl enable crond

2)crontab command
Open user's cron jobs --> crontab -e    --> open a editor/file u can mention the scrips and timinig

List cron jobs 			 --->crontab -l
Remove all cron jobs 	 ---> crontab -r
Edit another user's cron --->crontab -u username -e
Example : crontab -u ec2-user -e

------
